# Device Test Checklist

One dev build verifies all native features at once. Native dirs (`/ios`, `/android`)
are generated by `expo prebuild` and gitignored — never edit them by hand.

## Get the build on your phone

```bash
npx expo prebuild            # already run once; re-run after adding native deps
npm install                  # if pods changed: cd ios && pod install
npx expo run:ios --device    # pick your phone (needs Xcode signing + dev team)
# or: npx expo run:android --device
```

Then `npx expo start --dev-client` and connect the app to Metro.

## API connectivity from a phone

`https://cricketamigo.test` only resolves on this Mac (Kettle dnsmasq + self-signed
cert). For a real device:

- Easiest: run `cloudflared tunnel --url https://cricketamigo.test` (accepts the cert
  upstream) or `ngrok http https://cricketamigo.test`, then set `EXPO_PUBLIC_API_URL`
  to the tunnel URL before `expo start`.
- Or: adb reverse / device on same network pointing at the Mac's IP with the cert
  trusted — more fiddly, prefer the tunnel.

Websocket (Reverb): start `php artisan reverb:start` on the Mac; the app reads
`EXPO_PUBLIC_REVERB_HOST` — point it at the Mac's LAN IP or the tunnel.

## Known limits on device

- Stream console camera can't record while streaming — use record mode, upload later.
- PHP `upload_max_filesize` on Kettle FPM may reject clips >2 MB until php.ini is raised.
- `expo-mediapipe-pose` declares peer `expo@^57` (installed on 58 via legacy-peer-deps);
  if pose crashes, first thing to check is that peer gap.
